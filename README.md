# Grub-Theme---Three-Kingdoms-Shu-Kingdom
Grub Theme for Three Kingdoms: Shu Kingdom

First Clone the repo use:
git clone https://github.com/13atm01/GRUB-Theme.git

CD to the cloned repo:
CD Grub-Theme---Three-Kingdoms-Shu-Kingdom

Choose a theme eg.
GuanYu

Move the folder to the grub theme folder.
mv GuanYu  /boot/grub/themes/

Update grub settings:
sudo update-grub

or for Arch Linux
sudo grub-mkconfig -o /boot/grub/grub.cfg      #if you use Arch, use this instead "sudo update-grub"
